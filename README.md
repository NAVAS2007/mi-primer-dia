# Mi Primer Día

## 1. Nombre y frase

**Mi Primer Día**

Es un juego donde vives tu primer día de trabajo como programador junior, y cada decisión que tomas cambia cómo te va.

## 2. Qué hace y cómo se usa

Recorre seis momentos de tu primer día como programador junior y observa cómo tus decisiones afectan el ánimo y la reputación.
Elige una de tres opciones por momento; también puedes pedir ayuda una vez por partida.
Pulsa **Empezar** para jugar; usa las teclas **1**, **2** y **3** para elegir, **A** para pedir ayuda y **R** para reiniciar.

## 3. Enlace para abrirlo

Abre la versión publicada en GitHub Pages: <https://navas2007.github.io/mi-primer-dia/>

## 4. Cómo correrlo en otra máquina

Instala Node.js 22 o posterior y ejecuta desde la carpeta del proyecto:

```sh
npm install
npm run dev
```

Abre <http://localhost:5173/> en el navegador. Para compilar y probar el proyecto:

```sh
npm test
npm run build
```
